# Student Result Management System 🎓

A simple Python application for managing student examination results.

## Features

- Add student records
- Calculate total marks
- Calculate percentage
- Automatically assign grades
- Check pass/fail status
- Search for students
- Find the top-performing student

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run

Clone the repository and run:

```bash
python result_management.py
